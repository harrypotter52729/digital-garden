## js-weak-typing-and-dynamic-types


JavaScript is a **weakly typed** (or dynamically typed) language. Unlike strongly typed languages (like Java or Rust), variables in JavaScript **are not bound to a specific data type.**

- A variable can hold a `Number` at one moment and `String` at next.  JS engine automatically converts types to perform operations and to prevent bugs.

> "A variable can start as a number and become a string later."

There are two types of conversion
1. **Explicit :** This is manually converted by the user.
2. **Implicit :** Js automatically converts the data types.
