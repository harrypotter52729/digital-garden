## js-difference-ifelse-and-switch

### if else

if we want to check the condition against the range of data or complex conditions, here ***data is flexible***

### Switch

Here ***data is fixed***, If we want to execute the condition against the fixed data value.

It **uses strict equality ( === )** to check for the condition
